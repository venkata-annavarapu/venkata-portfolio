# How Generative LLMs Are Trained

A portfolio microsite for a three-slide visual explaining the generative LLM training lifecycle, resource demands, and disclosed model examples.

## View locally
Open `index.html` in a browser. The page is self-contained and uses local image previews and downloads from `assets/`.

## Publish with GitHub Pages
1. Add the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After Pages finishes deploying, use the public site URL as the submission link.

The site links to the editable PowerPoint and explanatory Word note. Sources and disclosure caveats are included on the page and in the files.
