Architecture

How data flows through a network

Data enters at the input layer, passes through one or more hidden layers where each neuron combines and transforms it, and leaves at the output layer as a prediction. Training compares that prediction with the true answer and sends a correction backward through the network.

Each line is a weight. Each circle is a neuron. The arrows run forward during prediction and backward during training.

Component 1 and 2

Layers and neurons

Layers

A layer is a group of neurons that receive the same input and produce the same kind of output. The input layer holds the raw features, hidden layers transform them, and the output layer gives the final prediction. More layers let a network learn more abstract patterns, at the cost of more computation.

Neurons

A neuron takes a weighted sum of its inputs, adds a bias, and passes the result through an activation function.

output = f(w₁x₁ + w₂x₂ + … + b)
Component 3

Weights and biases

Weights are the learned numbers that set how strongly one neuron's output influences the next. A large positive weight amplifies a signal, a negative weight reverses it, and a weight near zero nearly ignores it. The bias shifts the neuron's threshold so it can fire even when inputs are small. Training consists of adjusting these values until predictions improve.

Component 4

Activation functions

Activation functions add non-linearity. Without them, a stack of layers collapses into a single linear transformation, no matter how deep the network is.

Component 5

Loss functions

A loss function converts the gap between prediction and truth into a single number. Lower is better, and that number is what training tries to reduce.

Mean squared error

For regression, such as predicting a price. It averages the squared differences, so large mistakes are penalized heavily.

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

Cross-entropy

For classification. It measures how far the predicted probability is from the correct class, and punishes confident wrong answers strongly.

L = −Σ yᵢ log(ŷᵢ)
Component 6

Optimization algorithms

Backpropagation computes how much each weight contributed to the loss, expressed as a gradient. An optimizer uses those gradients to update the weights. The learning rate controls the size of each step: too large and training overshoots, too small and it crawls.

Gradient descent

Moves every weight a small step in the direction that lowers the loss, using the full dataset for each step.

Stochastic gradient descent

Updates the weights using one example or a small batch at a time. Each step is noisier but much faster, and the noise can help escape poor solutions.

Adam

Adapts the step size for each weight using running averages of past gradients. It often works well with little tuning, which makes it a common default.

Summary

Why visualizing neural networks matters

A diagram makes the flow of data and the role of each component visible at a glance. Seeing the layers, weights, and gradients together makes it easier to diagnose why a model underperforms and to explain its behavior to others.

  1. Every neuron computes a weighted sum, then applies an activation function.
  2. Activations provide the non-linearity that gives depth its value.
  3. The loss function defines what "good" means for the task.
  4. Optimizers turn gradients into weight updates, and the learning rate governs how big each update is.
